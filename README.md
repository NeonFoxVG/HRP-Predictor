# High-Risk Pregnancy Predictor

*A machine learning project built in Python using Random Forest and Explainable AI (XAI) to predict high-risk pregnancies and provide transparent model predictions.*

## Features

* High-risk pregnancy prediction using Random Forest
* SHAP feature importance explanations
* LIME local prediction explanations
* Interactive Streamlit dashboard
* Risk factor and prediction visualization

## Tech Stack

* Python
* Random Forest
* SHAP
* LIME
* Streamlit
